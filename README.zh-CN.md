# cpp-course-designs

两个 C++ 课程设计——职工管理系统与通讯录系统。

<sub>C++ · Visual Studio 工程</sub>

---

## 两个项目

| 项目 | 做什么 |
|---|---|
| 职工管理系统 | 记录、查找、排序、文件持久化 |
| 通讯录管路系统 | 联系人、分组、查询 |

两个都是课程设计做的控制台程序：每个实体一个类、一个菜单循环、持久化到本地文件。

## 说明

按原样保留，包括原始的工程目录名。改名会破坏 `.sln` 和 `.vcxproj` 里 Visual Studio 按目录解析的相对路径。

## 构建

用 Visual Studio 打开 `.sln` 直接构建。
