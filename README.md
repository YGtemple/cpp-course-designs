# cpp-course-designs

Two C++ course projects — a staff management system and an address book.

<sub>C++ · Visual Studio projects</sub>

---

## The two projects

| Project | What it does |
|---|---|
| 职工管理系统 (staff management) | records, search, sort, file persistence |
| 通讯录管路系统 (address book) | contacts, grouping, lookup |

Both are console applications built as coursework: classes per entity, a menu loop, and persistence to a local file.

## Note

Kept as written, including the original project folder names. Renaming them would break the `.sln` and `.vcxproj` paths that Visual Studio resolves relative to the directory.

## Building

Open the `.sln` in Visual Studio and build.
